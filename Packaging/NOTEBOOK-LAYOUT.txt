================================================================
  BtP OVEN  -  NOTEBOOK / FOLDER LAYOUT (visual)
================================================================

Copy this page into OneNote / Notion / a text file.  It is the
"where does this audio go" map for the whole training system.


----------------------------------------------------------------
A. THE BIG PICTURE
----------------------------------------------------------------

   YOU MAKE / GENERATE AUDIO IN THE PLUGIN
                    |
                    |  press TRAIN (or TRAIN & SAVE)
                    v
   +---------------------------------------------+
   |  %APPDATA%\BtP Oven\Training\               |
   |                                             |
   |   Vocals\      Loops\      Variants\        |
   |   OneShots\    Stems\                       |
   +---------------------------------------------+
                    |
                    |  run one Python script (GPU)
                    v
   +---------------------------------------------+
   |  NEW MODEL (.onnx)                          |
   |   %APPDATA%\BtP Oven\Models\RVC\voices\     |
   +---------------------------------------------+
                    |
                    |  restart plugin / reopen page
                    v
   NEW VOICE APPEARS IN THE VOICE DROPDOWN

   SAME CAPTURES CAN ALSO TRAIN AN ACE-STEP LORA
                    |
                    |  AI GEN -> TRAIN LORA
                    v
   +---------------------------------------------+
   |  %APPDATA%\BtP Oven\LoRAs\<name>\           |
   |      adapter_model.safetensors              |
   |      adapter_config.json                    |
   +---------------------------------------------+
                    |
                    |  auto-selects when finished
                    v
   LORA PICKER -> APPLY -> GENERATE

C. "WHAT BUTTON SAVES WHERE" CHEAT SHEET
----------------------------------------------------------------

  +----------------+-------------+---------------------------------+
  | PAGE           | BUTTON      | SAVES TO                        |
  +----------------+-------------+---------------------------------+
  | VOICE          | TRAIN&SAVE  | Training\Vocals                 |
  | AI GEN         | TRAIN       | Training\Loops                  |
  | AI GEN (sung)  | TRAIN       | Training\Vocals                 |
  | AI GEN         | TRAIN LORA  | LoRAs\<name>\ (adapter folder)  |
  | SHOTS          | TRAIN       | Training\OneShots\<category>    |
  | SHOTS (RAVE)   | TRAIN VAR   | Training\Variants               |
  | STEM drums     | TRAIN       | Training\Stems\drums            |
  | STEM bass      | TRAIN       | Training\Stems\bass             |
  | STEM other     | TRAIN       | Training\Stems\other            |
  | STEM vocals    | TRAIN       | Training\Stems\vocals           |
  +----------------+-------------+---------------------------------+

  Note: the plugin picks the folder from WHAT the audio is, not from
  which page you are on.  A sung AI take goes to Vocals even though
  you pressed the button on the AI GEN page.

F. NAMING RULES (so files stay findable)
----------------------------------------------------------------

  The plugin names captures automatically:
      <prompt-slug>_<timestamp>.wav

  When you save something by hand, use:

      <artist-or-source>_<type>_<bpm>_<key>_<take>.wav

  examples:
      btp_vocal_rnb_140_Fmin_take03.wav
      btp_drum_trap_140_Fmin_loop01.wav
      btp_oneshot_cash_metallic_01.wav

  Keep 10+ minutes of ONE voice in Vocals\ before training.
  Keep ONE style / tempo family per Loops\ subfolder if you add
  subfolders of your own.
