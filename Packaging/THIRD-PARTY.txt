AUDIT NOTES - WHAT CHANGED AND WHY
----------------------------------------------------------------

This inventory was checked on 2026-11-05 against the upstream
LICENSE files and model cards, not against summaries. Three entries
were corrected during the audit:

  RAVE
    Earlier assumption: MIT code, with separate weight terms.
    Reality: the acids-ircam/RAVE repository ships CC-BY-NC 4.0,
    and voice_multi is also CC-BY-NC 4.0. Treated as non-commercial
    for both code and weights. This is why a paid build must remove
    or replace RAVE.

  ACE-Step
    Earlier assumption: MIT.
    Reality: the framework code is Apache-2.0; the model weights are
    MIT. Both permit commercial use; Apache adds a NOTICE and a
    "state your changes" obligation.

  JUCE
    Earlier assumption: GPLv3 or commercial.
    Reality: JUCE 9 is AGPLv3 or a JUCE licence tier. The free tier
    is Starter (revenue up to $20,000); Indie and Pro are paid.
    This project is licensed under JUCE Indie, which covers closed-
    source distribution up to USD 300,000/year.

Why the confusion happens: a repository can have MIT code and
non-MIT weights, and search results / chat assistants usually quote
the first licence tag they see. Always open LICENSE, the model card,
and the HF "license:" tag for the exact files you ship.

If you reuse this project, keep this file with it. It is the record
that the licensing was checked deliberately rather than assumed.
