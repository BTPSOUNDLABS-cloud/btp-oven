BtP Oven 1.0.0 - first public build.

VST3 + Standalone for Windows x64.
Three loop lanes, ACE-Step generation, Demucs stems, RVC voices,
RAVE mutation, auto-tune.

Download the zip, extract it, right-click INSTALL.cmd -> Run as administrator.
Read README.txt first. Licences: see LICENSING.txt and THIRD-PARTY.txt.

Source available. This free build is not for resale and contains
CC-BY-NC components (RAVE). A commercial build without RAVE is
covered in BUILD-VARIANTS.txt.

Includes: VST3, standalone app, Demucs / ContentVec / RMVPE / RAVE models.

Update (2026-11-07): train_voice.py now trains RVC voices on Windows
with CUDA torch. Fixes a crash caused by single-GPU DDP and the ONNX
export step. See TRAINING-GUIDE.txt section 0 for the tested setup.

Update (2026-11-09): global PLAY / PAUSE / STOP in the header on every
page (pause freezes the loop playheads, stop rewinds them); DAW tempo
sync plus a manual BPM box; draggable region handles on the oven
waveform; IN / OUT trim sliders on the VOICE page source vocal;
master.json preset bank (15 R&B / dark trap tracks, loops and vocals)
in the AI page; TRAIN now captures the selected loop when there is no
AI take and shows the saved path; LORA DIR opens the LoRA folder and
rescans it.
